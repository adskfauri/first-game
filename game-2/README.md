# 게임 2 - 완전범죄

집들이에서 여러 명이 각자 휴대폰으로 접속해 플레이하는 비밀 미션 게임입니다.

## 포함 기능

- 방 생성 및 6자리 방 코드
- 닉네임 참가
- 최대 10명
- 방장 시작/종료
- 참가자별 랜덤 비밀 미션
- 특정 참가자 타깃 지정
- 미션 성공 신고
- 수상한 참가자 신고
- 자동 벌칙 계산
- 누적 벌칙 랭킹
- 모바일 반응형 화면

## 1. Firebase 설정

1. Firebase Console에서 프로젝트 생성
2. `Realtime Database` 생성
3. 웹 앱 추가
4. Firebase 설정값을 `firebase-config.js`에 복사
5. Realtime Database 규칙을 아래처럼 임시 설정

```json
{
  "rules": {
    "rooms": {
      "$roomCode": {
        ".read": true,
        ".write": true
      }
    }
  }
}
```

집들이가 끝난 뒤에는 DB 규칙을 닫거나 프로젝트를 삭제하는 것을 권장합니다.

## 이번 수정 내용

- 총 미션 수: 104개
- 미션 난이도 진행 중 비공개
- 결과에서 순한맛/눈치싸움/고난도/광기 공개
- 신고 대상자에게 익명 신고 팝업과 진동
- 동일 대상 중복 신고 방지
- 결과에서 신고자 → 피신고자 공개
- 개인별 신고/피신고 통계 제공


## 재미 요소 추가

- 결과 화면 최상단에 벌칙자 이름, 모금 수, 판정 이유를 크게 표시
- 세부 판정 근거는 접어서 확인
- 라운드마다 무작위 시점에 전원 동시 돌발 생존전 발생
- 제한 시간 내 버튼을 누르지 못하거나 가장 늦은 사람은 추가 한 모금
- 돌발 이벤트 결과도 최종 벌칙에 합산


## 긴급 재판 업데이트

- `이의 있습니다!` 클릭 시 모든 플레이와 타이머 즉시 정지
- 개인당 라운드 1회만 이의제기 가능
- 용의자 선택 및 5자 이상의 근거 필수
- 최초 제보자와 참가자 모두 익명 채팅 참여
- 방장이 익명 토론 종료 후 범인/무죄 투표 시작
- 실제 미션 대상과 최초 제보자가 일치하는지 자동 판정
- 정확한 제보: 제보자, 용의자, 미션, 모든 투표 결과 공개
- 허위 제보: 최초 제보자만 공개하고 랜덤 민망 벌칙 부여
- 민망 벌칙 24종
- 재판 종료 후 남은 시간부터 게임 재개


## 초대형 콘텐츠 확장

- 비밀 미션: 650종
- 민망 행동 벌칙: 242종
- 모든 미션 문구 중복 제거 완료
- 대화, 특정 단어 유도, 행동 유도, 집들이, 사물, 고난도, 광기형 구성
- 말투, 상황극, 노래, 몸동작, 물건 연기, 상호작용 벌칙 구성


## 최종 리빌드 규칙

1. 플레이어는 비밀 지령을 수행합니다.
2. 의심한 플레이어는 용의자, 추측한 지령, 근거를 작성합니다.
3. 제출 즉시 모든 화면과 타이머가 정지합니다.
4. 익명 공개 토론 후 지목당한 사람이 실제 지령과 비교해 직접 판정합니다.
5. 맞으면 실제 지령과 제보자가 공개됩니다.
6. 틀리면 실제 지령은 숨기고 제보자가 민망 벌칙을 수행합니다.
7. 벌칙 수행 완료 후 남은 시간부터 게임이 재개됩니다.
8. 명백한 거짓 판정만 방장이 뒤집을 수 있습니다.

### 권장 시간

- 빠른 게임: 5분
- 기본 추천: 7분
- 대화가 많은 모임: 10분
- 재판 시간은 제한시간에서 차감되지 않습니다.
- 4라운드 기준 약 32~42분을 예상합니다.


## 파티 업그레이드 적용 내용
- 신고 입력에서 별도 근거 입력란 제거: 근거는 익명 재판 채팅에서 설명
- 지령이 발각된 참가자는 방해자 모드로 전환
- 방해 카드 5종: 지령 가리기, 문장 섞기, 가짜 지령, 가짜 대상, 완료 버튼 도망가기
- 돌발 미니게임 5종: 긴급 버튼, 연타, 77 멈추기, 폭탄 버튼, 진짜 버튼 찾기
- 방해자도 재판·투표·돌발게임에 끝까지 참여
